###### **Full-Stack Real-Time Chat Platform**

A modern, full-stack real-time chat application engineered for speed, scalability, and seamless user interaction. Built on top of Next.js and React, this application leverages Redux for centralized, predictable state management across complex user sessions and active chat rooms.

Key Architectural Features:

* **Real-Time Communication:** Low-latency, bi-directional event delivery powered by WebSockets for instant messaging and live presence tracking.



* **Database \& Data Persistence:** Integrated with MongoDB for fast, flexible document storage handling user profiles, message histories, and channel metadata.



* **Cloud Storage \& Media Handling:** Secure media uploads and file sharing backed by AWS S3 bucket storage.



* **Optimized UX:** Production-ready UI rendering, efficient client-side caching, and responsive design optimized for mobile and desktop web browsers.
