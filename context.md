## Cache Information

unsceen-message-count-${userId}-${senderId} - Count of unsceen messages by user id and sender id
chat-room-${user1Id}-${user2Id} - Chat room id by user1 id and user2 id
user-contacts-${userId} - User contacts by user id
user-${id} - User details by user id
user-session-${sessionId} - User session details by session id
user-chat-rooms-${userId} - User chat rooms by user id
